# Rishvin Labs

A premium, modern, high-converting tech studio website built using a pure HTML + CSS + JavaScript stack.

## Tech Stack
- Frontend: HTML5 + CSS3 + JavaScript
- Styling: Custom CSS Architecture (Dark Luxury Tech)
- Hosting: GitHub Pages
- Icons: Lucide Icons
- Fonts: Google Fonts (Sora & Inter)

## Directory Structure
- `assets/css/`: Modular CSS files (variables, reset/style, animations, components)
- `assets/js/`: Modular JS functionality (navbar, animations, Github API sync)
- `assets/images/`: Images organized by section
- `data/`: JSON data for projects, services, testimonials
- `*.html`: Pages (Home, About, Services, Projects, Contact)

## Local Development
Since this is a vanilla stack, you can run this project locally using any basic HTTP server. For example:

### Using Python:
```bash
python3 -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.

### Using Node (Live Server):
```bash
npx live-server
```
